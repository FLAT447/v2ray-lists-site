# Гайды по клиентам

## Android (v2rayNG)

**Скачать:** [v2rayNG](https://github.com/2dust/v2rayNG/releases/download/2.3.2/v2rayNG_2.3.2-universal.apk)

1. Скачайте и установите **v2rayNG**.
2. Скопируйте в буфер обмена ссылку на конфиг из списка выше.
3. Откройте **v2rayNG**: справа сверху нажмите **+** → **Импорт из буфера обмена**.
4. Справа сверху откройте меню **три точки** → **Проверить задержку профилей**. После проверки в том же меню выберите **Сортировать по результатам теста**.
5. Выберите сервер с наименьшим пингом и нажмите **▶** (подключить) в правом нижнем углу.

### Решение проблем

**Нет интернета при подключении**
Убедитесь, что включён VPN-режим в настройках. Попробуйте выбрать другой сервер с меньшим пингом.

**Конфиги не появились**
Убедитесь, что URL скопирован полностью. Попробуйте вставить его вручную через «Добавить профиль» → «Тип: Subscription».

**Ошибка "Handshake timeout"**
Сервер временно недоступен. Выберите другой сервер из списка или повторите проверку задержки.

**Ошибка "Closed pipe"**
Перезапустите приложение и попробуйте подключиться снова. Если не помогает — смените конфиг.

### Как обновить конфиги?

1. Нажмите на **иконку трёх полосок** в **левом верхнем углу**.
2. Выберите вкладку **«Группы»**.
3. Нажмите на **иконку кружка со стрелкой** в **правом верхнем углу**.

## Android TV (v2rayNG)

**Скачать:** [v2rayNG](https://github.com/2dust/v2rayNG/releases/download/2.3.2/v2rayNG_2.3.2-universal.apk)

1. Установите **v2rayNG** и зайдите в него.
2. Скачайте один из QR-кодов из списка выше.
3. В **v2rayNG** нажмите **+** справа сверху → **Импорт из QR-кода**, затем выберите картинку (иконка фото в правом верхнем углу).
4. Меню **три точки** справа сверху → **Проверить задержку профилей**, затем в том же меню — **Сортировать по результатам теста**.
5. Выберите сервер с наименьшим пингом и нажмите **▶** в правом нижнем углу.

### Решение проблем

**Приложение не устанавливается**
Включите установку из неизвестных источников в настройках безопасности Android TV.

**Не работает пульт в приложении**
Используйте физическую мышь или управление через ADB для навигации в приложении.

**QR не сканируется**
Убедитесь, что на экране ТВ изображение QR крупное и не смазано. Попробуйте другой файл из папки или импорт по ссылке с другого устройства.

### Как обновить конфиги?

1. Нажмите на **иконку трёх полосок** в **левом верхнем углу**.
2. Выберите вкладку **«Группы»**.
3. Нажмите на **иконку кружка со стрелкой** в **правом верхнем углу**.

## Windows / Linux (Throne)

- [Скачать для Windows 10 / 11](https://github.com/throneproj/Throne/releases/download/1.2.2/Throne-1.2.2-windows64.zip)
- [Скачать для Windows 7 / 8 / 8.1](https://github.com/throneproj/Throne/releases/download/1.2.2/Throne-1.2.2-windowslegacy64.zip)
- [Скачать для Linux](https://github.com/throneproj/Throne/releases/download/1.2.2/Throne-1.2.2-linux-amd64.zip)

1. Скачайте **Throne** для своей системы по ссылкам выше.
2. Скопируйте в буфер обмена ссылку на конфиг из списка выше.
3. В Throne: **Профили** → **Добавить профиль из буфера обмена**.
4. Выделите все конфиги (**Ctrl+A**). В меню **Профили** выберите **Тест задержки (пинга) выбранного профиля** и дождитесь окончания (во вкладке **Логи** появится **«Тест задержек (пинга) завершён!»**).
5. Нажмите на заголовок колонки **«Задержка (пинг)»** для сортировки.
6. В верхней части окна включите **«Режим TUN»** (галочка).
7. Выберите конфиг с наименьшей задержкой: **ЛКМ** по строке → в меню — **Запустить**.

### Ошибка MSVCP / VCRUNTIME?

Если программа не запускается, удалите старые версии Visual C++ и установите пакет: [Скачать Visual C++ Runtimes](https://aka.ms/vs/17/release/vc_redist.x64.exe)

Распакуйте и запустите install_bat.all от имени администратора.

### Решение проблем

**Антивирус блокирует приложение**
Добавьте Throne в исключения антивируса. Это ложное срабатывание — VPN-клиенты часто блокируются антивирусами.

**Нет доступа в интернет после подключения**
Убедитесь, что включён «Режим TUN» в верхней части окна Throne. Попробуйте запустить приложение от имени администратора.

**Ошибка "Handshake timeout"**
Сервер временно недоступен. Выберите другой профиль из списка.

### Как обновить конфиги?

1. Нажмите кнопку **«Настройки»**.
2. Выберите **«Группы»**.
3. Нажмите **«Обновить все подписки»**.

## iOS / iPadOS (Streisand)

**Скачать:** [Streisand (App Store)](https://apps.apple.com/us/app/streisand/id6450534064)

1. Установите **Streisand** из App Store.
2. Скопируйте в буфер обмена ссылку на конфиг из списка выше.
3. Откройте Streisand и нажмите **+** → **Import from Clipboard** (добавить из буфера).
4. Зажмите добавленную подписку и выберите **Latency** (задержка).
5. Выберите сервер с наименьшей задержкой и нажмите **Включить** вверху экрана.

### Решение проблем

**Streisand недоступен в моём регионе**
Смените регион App Store на США или другой поддерживаемый регион через настройки Apple ID.

**Конфиги не загружаются**
Убедитесь, что ссылка скопирована полностью без лишних пробелов. Попробуйте удалить подписку и добавить снова из буфера.

### Как обновить конфиги?

1. Зажмите подписку и выберите **Update** (обновить).

## MacOS (Hiddify)

**Скачать:** [Hiddify (macOS)](https://github.com/hiddify/hiddify-app/releases/download/latest/Hiddify-MacOS.dmg)

1. Скачайте и установите **Hiddify** по ссылке выше.
2. Нажмите **«Новый профиль»**.
3. Скопируйте в буфер обмена ссылку на конфиг из списка выше.
4. Нажмите **«Добавить из буфера обмена»**.
5. Откройте **«Настройки»** и установите **«Вариант маршрутизации»** на **«Индонезия»**.
6. В левом верхнем меню нажмите на иконку настроек и выберите **«VPN сервис»**.
7. Включите **VPN**, нажав на иконку по центру.
8. Чтобы сменить сервер: включите **VPN** и перейдите на вкладку **«Прокси»**.

### Решение проблем

**macOS блокирует запуск приложения**
Перейдите в Системные настройки → Конфиденциальность и безопасность → разрешите запуск Hiddify.

**VPN-профиль не устанавливается**
Разрешите запрос на установку VPN-конфигурации, нажав «Разрешить» в появившемся диалоге macOS.

### Как обновить конфиги?

1. Откройте **Hiddify** и выберите нужный профиль.
2. Нажмите **слева от названия профиля на иконку обновления**.
